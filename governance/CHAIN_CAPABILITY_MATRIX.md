# Chain Capability Matrix

This matrix records intended research boundaries, not enabled production support.

| Chain | Ordering/observation model to research | F0 status | Execution status |
|---|---|---|---|
| Ethereum | Public state plus responsible private bundle/backrun paths | Schema only | Disabled |
| Base | Flashblocks pre-confirmed state and sub-block event stream | Schema only | Disabled |
| Arbitrum | Sequencer ordering and Timeboost economics | Schema only | Disabled |
| BNB Smart Chain | Public flow plus builder/PBS capability | Schema only | Disabled |
| Solana | Separate SVM/Jito account-lock and bundle model | Schema only | Disabled |

No generic adapter may claim support based only on EVM compatibility. Ordering, fee, state-age, simulation, and inclusion contracts are chain-specific.
