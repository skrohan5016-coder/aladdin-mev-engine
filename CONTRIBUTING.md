# Contributing

All changes must preserve fail-closed F0–F6 authority boundaries, exact integer/canonical evidence semantics, zero third-party runtime dependencies, and read-only deterministic CI. New F6 work must include adversarial tests and closed schema/lock updates.

Never add live endpoints, credentials, private keys, local signing, HTTP/RPC clients, transaction or bundle submission, deployment, execution, inclusion claims, or profit guarantees without a separately governed milestone and explicit human approval.
