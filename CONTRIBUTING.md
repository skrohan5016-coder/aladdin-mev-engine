# Contributing

All changes must preserve fail-closed F0–F8 authority boundaries, exact integer/canonical evidence semantics, complete historical-attempt retention, zero third-party runtime dependencies, and read-only deterministic CI. New F8 work must include adversarial tests and closed schema/lock updates.

Never add live endpoints, credentials, private keys, local signing, HTTP/RPC clients, polling, transaction or bundle submission, deployment, execution authority, automatic production promotion, token-balance assumptions, realized-profit claims, confidence guarantees, or profit guarantees without a separately governed milestone and explicit human approval.
