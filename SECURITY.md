# Security Policy

F4 is offline, recorded-input, proof-authenticated, explicit-model-bound, cost-complete for its governed recorded categories, and shadow-only. It has no network client, RPC credential path, broadcaster, signer, private-key handling, deployment script, mainnet execution authority, production model approval, inclusion guarantee, or live-profit claim.

Never commit wallet material, seed phrases, private keys, RPC or builder credentials, deployment authorities, treasury access, production database credentials, raw `.env` files, or private strategy configuration.

Any future live observation, production model approval, EVM execution, signing, submission, deployment, or money movement requires a later governed milestone, updated threat model, adversarial tests, exact-head review, and Rohan's explicit approval.
