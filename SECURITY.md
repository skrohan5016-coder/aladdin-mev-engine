# Security Policy

F3 is offline, recorded-input, proof-authenticated, explicit-model-bound, and shadow-only. It has no network client, RPC credential path, broadcaster, signer, private-key handling, deployment script, mainnet execution authority, production model approval, or net-profit claim.

Never commit wallet material, seed phrases, private keys, RPC or builder credentials, deployment authorities, treasury access, production database credentials, raw `.env` files, or private strategy configuration.

Any future live observation, token-model approval, EVM simulation, signing, submission, deployment, or execution requires a later governed milestone, updated threat model, adversarial tests, exact-head review, and Rohan's human approval.
